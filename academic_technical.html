Senior Project Deep-Dive

Svatantrata.net & Enterprise Network Simulation

The Summary: The purpose of this project is to develop a comprehensive personal portfolio website, Svatantrata.net, to showcase my technical projects and integrate seamlessly with professional platforms like LinkedIn and GitHub. Concurrently, it involves designing and simulating a functional enterprise-grade network infrastructure. This ongoing effort leverages industry-standard hardware, including an Arista Datacenter Switch, HPE and Dell Servers, and Mikrotik routing equipment, to gain hands-on experience in enterprise systems engineering.

The Research: Primary sources included extensive technical documentation and architecture guides from Arista, HPE, Dell, and Mikrotik, supplemented by enterprise networking best practices and online technical communities. The central problem I aimed to solve was bridging the gap between theoretical networking concepts and practical, enterprise-level deployment, while simultaneously creating a centralized digital identity to document and share this complex process.

The Outcomes: The project has resulted in the successful deployment and continuous integration of Svatantrata.net as the central hub for my professional identity. The physical prototype of the enterprise network is currently active and ongoing, featuring integrated hardware from multiple enterprise vendors to simulate a realistic, scalable datacenter environment. I have successfully established core routing and switching capabilities within this lab.

BTC Integration: This project applied core technical competencies in network topology design, server hardware configuration, and system administration, demonstrating skills essential for modern IT and enterprise networking roles.
